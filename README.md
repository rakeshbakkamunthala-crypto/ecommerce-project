# Online E-Commerce Shopping Platform

A Python Full Stack E-Commerce Shopping Platform developed using Django and MySQL as part of a Python Full Stack Internship.

## Project Overview

This project is a complete web-based e-commerce application that allows users to browse products, view product details, add products to a shopping cart, checkout, place orders, and view their order history.

The application also includes Django Admin for managing categories, products, carts, cart items, orders, and order items.

## Project Workflow

1. User registers or logs into the application.
2. User browses available products.
3. User views product details.
4. User adds products to the cart.
5. User proceeds to checkout.
6. User enters shipping information and selects a payment method.
7. Order is created and stored in the MySQL database.
8. User can view order history and order details.
9. Admin can manage application data through Django Admin.
